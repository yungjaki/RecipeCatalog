# Рецептник – каталог за готварски рецепти

Курсов проект по Софтуерно инженерство, **Задание №1 (Екип 1)**.
Екип: Димитър Димитров, Иван Кечев · 12а клас · Ръководител: Катя Семкова

Уеб приложение за съхранение, каталогизиране и интерактивно търсене на кулинарни рецепти.

## Функционалности

- 4 категории рецепти: Салати, Супи, Основни ястия, Десерти (изискване: поне 3)
- Всяка рецепта има име, списък с продукти, начин на приготвяне, рейтинг и изображение
- Търсене по име, по съставка или навсякъде; няколко продукта се разделят със запетая („домати, сирене“) и трябва да присъстват всички
- Филтри по категория и минимален рейтинг, подреждане по име, рейтинг, време или най-нови
- Добавяне, редакция и изтриване на рецепти, качване на снимка (JPG/PNG/WEBP до 2 MB)
- Оценяване с 1–5 звезди; показва се средната оценка
- Адаптивен (mobile-first) интерфейс

## Стартиране

Нужен е [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
dotnet run --project src/RecipeCatalog.Web --urls http://localhost:5080
```

Отворете http://localhost:5080. При първо стартиране базата `src/RecipeCatalog.Web/App_Data/recipes.db` се създава и се попълва с 13 примерни рецепти.
